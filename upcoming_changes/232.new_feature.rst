In Present mode all four split layouts render as chosen (text above or below the picture as well as beside it), text slides scale their type to fill the stage, and a PNG dropped on a split slide's picture slot fills that slot instead of being added below. Slides now size to the display: moving the presentation to a projector, maximising it or changing the resolution scales text, pictures and split panes together, and live figures redraw sharply at the new size.
